The skills cycle

How it works, step by step.

Every practical task, from welding a joint to icing a cake, follows four steps.

  1. 1

    Plan

    Read the drawing or recipe, list the materials and the order of work.

  2. 2

    Make

    Work carefully and accurately, using the right tools safely.

  3. 3

    Check

    Measure and inspect the work against the specification.

  4. 4

    Improve

    Ask for feedback and make the next piece even better.

Workshop safety

Stay safe, work well.

  1. Wear the right PPE: goggles, overalls and closed shoes.
  2. Only use a machine after you have been shown how.
  3. Keep the floor and bench clear and dry.
  4. Never leave a hot or running tool unattended.
  5. Report damaged tools straight away.
  6. Clean and return every tool at the end.
