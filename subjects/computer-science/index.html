Computer Science. Think like a computer, build like an engineer.

Computer Science teaches how computers work and how to instruct them, so you can design programs and systems that solve real problems.

  • Technology
  • ZIMSEC · Cambridge-aligned
Download the study guide See the topics

Big ideas

Three ideas that hold it all together.

Master these and every topic in Computer Science becomes easier to understand and remember.

  1. 01

    Algorithms

    An algorithm is a precise set of steps that solves a problem. Good algorithms are correct, clear and efficient.

  2. 02

    Everything is binary

    Computers store numbers, text, photos and sound as 0s and 1s. Eight bits make one byte.

  3. 03

    Systems and networks

    Hardware, software and networks work together. The internet moves data in small packets between connected devices.

Key terms

Words to know by heart.

Examiners reward precise language. Learn each definition word for word.

Algorithm
A step-by-step set of instructions for solving a problem.
Bit
A single binary digit: 0 or 1.
Byte
A group of 8 bits.
Variable
A named location in memory that stores a value which can change.
Iteration
Repeating a set of instructions, for example with a loop.
Debugging
Finding and fixing errors in a program.
Protocol
A set of rules for how data is sent across a network.
Encryption
Scrambling data so that only authorised people can read it.

Study smarter

Four habits of top students.

  1. Write a little code every day.
  2. Trace an algorithm by hand before you run it.
  3. Learn the standard algorithms: linear search, bubble sort.
  4. Protect your accounts with strong passwords.

Check yourself

Try these, then reveal the answers.

Q1Convert the binary number 1011 to denary.+
Answer

11 (8 + 0 + 2 + 1).

Q2How many bits are there in 3 bytes?+
Answer

24 bits (3 × 8).

Q3What does this output? total ← 0; FOR i ← 1 TO 4: total ← total + i; OUTPUT total+
Answer

10 (1 + 2 + 3 + 4).
